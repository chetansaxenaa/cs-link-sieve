CS Link Sieve

Paste messy text, get clean website links.

Live demo

What it does

Pulls real website links out of any text you paste. Skips filenames like index.html, email addresses, and common noise domains (Google, analytics, social).

Features
Updates live as you type
Toggle between full URLs and domains only
Copy one link or all of them
Duplicates removed, results sorted
Use it

Download index.html and open it in a browser. That's it — one file, no install.
